# Gravity Glitch

Gravity Glitch is a browser-based 2D cyber runner game where players navigate a grid by jumping, flipping gravity, and dodging obstacles. The game features escalating sector levels, dynamic hazards like hunter drones and pincer gates, and score multipliers for near misses.

## How to Run

1. Download or clone this repository to your local computer.
2. Double-click the `gravity_glitch.html` file to open it in any modern web browser (such as Chrome, Edge, or Firefox).
3. Click the "INITIATE RUN" button on the main menu to start playing.

## Controls

* **Jump:** Space / ↑ / W / Left Click
* **Double High Jump:** Press the jump button twice
* **Pause:** P / ESC
* **Quick Restart:** R
